## Token architecture

coal.ui uses **OKLCH CSS custom properties** as its token layer. All component classes
reference these variables — so changing a variable changes every component that uses it.

```css
/* Override in your globals.css to customize */
:root {
  --primary: oklch(48% 0.28 264);   /* indigo instead of charcoal */
  --radius: 0.75rem;                /* rounder corners */
}
```

## Semantic tokens

| Token | Light | Dark | Usage |
|---|---|---|---|
| `--background` | `oklch(99% 0.004 75)` | `oklch(12% 0.010 75)` | Page background |
| `--foreground` | `oklch(14% 0.010 75)` | `oklch(95% 0.004 75)` | Default text |
| `--primary` | `oklch(22% 0.012 75)` | `oklch(92% 0.005 75)` | Primary actions |
| `--primary-foreground` | `oklch(98% 0.003 75)` | `oklch(14% 0.010 75)` | Text on primary |
| `--secondary` | `oklch(93.5% 0.008 75)` | `oklch(21% 0.012 75)` | Secondary actions |
| `--muted` | `oklch(93.5% 0.008 75)` | `oklch(21% 0.012 75)` | Subtle backgrounds |
| `--muted-foreground` | `oklch(48% 0.014 75)` | `oklch(63% 0.014 75)` | Placeholder / captions |
| `--border` | `oklch(87.5% 0.010 75)` | `oklch(22% 0.014 75)` | Borders |
| `--ring` | `oklch(22% 0.012 75)` | `oklch(75% 0.010 75)` | Focus rings |
| `--destructive` | `oklch(55% 0.24 29)` | `oklch(45% 0.20 29)` | Error / danger |
| `--brand` | `oklch(68% 0.20 55)` | `oklch(72% 0.20 55)` | Brand amber accent |
| `--radius` | `0.5rem` | `0.5rem` | Border radius base |

## Dark mode

coal.ui uses the `.dark` class on `<html>`. Toggle it with:

```tsx
document.documentElement.classList.toggle("dark")
```

## Why OKLCH?

OKLCH is perceptually uniform — the same `L` value appears equally bright across hues.
Coal.ui's warm hue-75 palette appears distinctly warmer than shadcn's zinc (hue 285).

## Custom theme example

```css
@layer base {
  :root {
    --background:         oklch(99.5% 0 0);
    --foreground:         oklch(12% 0.016 264);
    --primary:            oklch(52% 0.27 264);
    --primary-foreground: oklch(98% 0 0);
    --ring:               oklch(52% 0.27 264);
    --radius:             0.75rem;
  }
}
```
