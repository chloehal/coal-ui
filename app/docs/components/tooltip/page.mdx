---
title: Tooltip
description: A floating label that appears when the user hovers or focuses an element.
---

## Installation

```bash
npx shadcn add https://ui.chlohal.com/r/tooltip.json
```

## Usage

```tsx
import {
  Tooltip, TooltipContent, TooltipProvider, TooltipTrigger,
} from "@/components/ui/tooltip"
import { Button } from "@/components/ui/button"

export default function Example() {
  return (
    <TooltipProvider>
      <Tooltip>
        <TooltipTrigger render={<Button variant="outline">Hover me</Button>} />
        <TooltipContent>
          <p>Add to library</p>
        </TooltipContent>
      </Tooltip>
    </TooltipProvider>
  )
}
```

## Notes

- Wrap your app (or layout) with `<TooltipProvider>` once — it manages global hover delay.
- `TooltipTrigger` uses Base UI's `render` prop to delegate to your element.
- Keyboard: tooltip appears on focus, disappears on blur or `Escape`.

## Props

| Component | Key Props | Description |
|---|---|---|
| `TooltipProvider` | `delay`, `closeDelay` | Global hover delay (ms) |
| `Tooltip` | `open`, `onOpenChange`, `defaultOpen` | Root state |
| `TooltipTrigger` | `render` | Element that triggers the tooltip |
| `TooltipContent` | `className` | The floating label |
